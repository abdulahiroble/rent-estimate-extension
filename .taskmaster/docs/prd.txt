# Product Requirements Document: RentEst Browser Extension Revival

## Executive Summary
RentEst is a browser extension that provides instant rental price estimates for properties across the United States. Using the RentCast API, it delivers accurate rent estimates, comparable properties, and market insights directly in the browser, eliminating the need to visit multiple real estate websites.

## Product Vision
To become the go-to tool for real estate investors, landlords, and property managers who need quick, accurate rental pricing data while browsing the web.

## Target Users
1. Real Estate Investors - Quick property analysis while browsing listings
2. Landlords - Pricing research for rental properties
3. Property Managers - Portfolio rent optimization
4. Real Estate Agents - Quick comps for clients

## Core Features

### Phase 1: MVP (Weeks 1-2)
1. **Codebase Cleanup**
   - Remove all Twitter extension template code
   - Update branding from "Minimal Twitter" to "RentEst"
   - Clean up unused components and dependencies
   - Update manifest.json with correct extension details
   - Update README.md with RentEst information

2. **RentCast API Integration**
   - Sign up for RentCast API (free tier - 50 calls/month)
   - Create API service layer for RentCast endpoints
   - Implement rent estimate endpoint integration
   - Implement property search by address
   - Add error handling and rate limiting
   - Store API key securely in environment variables

3. **Core UI Components**
   - Address search input with autocomplete
   - Current location detection button
   - Rent estimate display (avg, low, high)
   - Loading states and skeleton screens
   - Error messages and empty states
   - Clean, modern UI using existing Tailwind setup

4. **Basic Functionality**
   - Search properties by address
   - Get rent estimates based on current location
   - Display rent estimate results
   - Show basic property information
   - Cache recent searches to reduce API calls

### Phase 2: Enhanced Features (Weeks 3-4)
1. **Comparable Properties**
   - Display 5-20 nearby rental comps
   - Show comp details (address, rent, features)
   - Map view of comparable properties
   - Filter comps by property type

2. **Market Insights**
   - Local market statistics
   - Average rents by zip code
   - Historical rent trends
   - Market performance indicators

3. **User Experience Improvements**
   - Save favorite properties
   - Recent searches history
   - Property comparison view
   - Export data as PDF (premium feature)

### Phase 3: Monetization (Week 5)
1. **Freemium Model Implementation**
   - Free tier: 10-20 lookups per month
   - Pro tier: Unlimited lookups ($9.99/month)
   - Integrate ExtPay payment system (already in codebase)
   - Usage tracking and quota management
   - Upgrade prompts and CTAs

2. **Premium Features**
   - Unlimited rent estimates
   - Detailed comparable properties (20 vs 5)
   - Historical trend data
   - PDF report generation
   - Custom branding on reports
   - Priority support

### Phase 4: Marketing & Launch (Week 6)
1. **Landing Page**
   - SEO-optimized landing page
   - Clear value proposition
   - Feature showcase
   - Pricing information
   - Sign-up CTA
   - Blog section for content marketing

2. **Browser Store Submissions**
   - Chrome Web Store submission
   - Firefox Add-ons submission
   - Microsoft Edge Add-ons submission
   - Prepare store assets (screenshots, descriptions)

3. **SEO & Content Strategy**
   - Target keywords: "rental estimates", "how much should i charge for rent", "property rent calculator"
   - Create blog posts targeting landlord pain points

## Technical Requirements

### Technology Stack
- **Frontend**: Next.js 13, React 18, TypeScript
- **Styling**: Tailwind CSS 3
- **Extension**: Chrome Extension Manifest V3
- **API**: RentCast API
- **Payment**: ExtPay
- **Maps**: Leaflet for map visualization
- **Charts**: Chart.js for trends

### API Integration
- **RentCast API Endpoints**:
  - Property search by address
  - Rent estimates (AVM)
  - Comparable properties
  - Market statistics
  - Historical trends

### Data Requirements
- 140M+ property records (via RentCast)
- Nationwide coverage (all 50 US states)
- Real-time data updates
- 38K+ zip codes for market data

### Performance Requirements
- Extension popup loads in < 2 seconds
- API responses cached for 24 hours
- Optimized for minimal memory usage
- Works offline with cached data

## Business Model

### Pricing Strategy
- **Free Tier**: 10-20 lookups/month, basic estimates
- **Pro Tier**: $9.99/month, unlimited lookups, premium features
- **API Costs**: RentCast Foundation plan ($74/month for 1,000 requests)

### Revenue Projections
- Month 1-3: 100 free users (testing)
- Month 4-6: 500 users, 50 paid ($500/mo revenue)
- Month 7-12: 2,000 users, 200 paid ($2,000/mo revenue)
- Year 2: 10,000 users, 1,000 paid ($10,000/mo revenue)

### Unit Economics
- Pro subscription: $9.99/month
- RentCast cost per lookup: ~$0.074
- Average 20 lookups/user/month: $1.48 cost
- Gross margin: ~85%

## Competitive Advantages
1. **Convenience**: Instant access via browser popup (no website visits)
2. **Speed**: One-click estimates from any webpage
3. **Location-aware**: Current location feature for quick lookups
4. **Clean UI**: No ads, focused experience
5. **Quality Data**: Powered by RentCast's 140M+ property database
6. **Affordable**: Lower cost than competitors

## Risks & Mitigation

### Technical Risks
- **API Rate Limits**: Implement caching and quota management
- **API Costs**: Monitor usage, optimize calls, tiered pricing
- **Data Accuracy**: Use RentCast's verified data sources

### Business Risks
- **Competition**: Focus on convenience and UX differentiation
- **User Acquisition**: SEO strategy and content marketing
- **Monetization**: Freemium model with clear value proposition
